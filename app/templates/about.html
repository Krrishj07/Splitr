About This Project

This is our MHacks 2025 project: a lightweight, privacy‑first tool to help roommates and teammates fairly split shared expenses and usage‑based bills. It combines a quick expense splitter, time‑based bill tracking, and a demo showcasing how computer vision can automate who’s currently using a shared resource.

What You Can Do

  • Expense Splitter: Split a single expense equally, by percentage, or by exact amounts.
  • Dynamic Split (Bill Tracking): Track time spent by each user on recurring bills (e.g., Internet, Electricity) and generate a monthly report.
  • Facial Recognition Demo: Prototype that recognizes a user to start/stop a timer automatically for hands‑free tracking.
  • Secure Login: Auth0‑backed authentication with a simple dashboard and profile.

How It Works

  1. Sign in to access your dashboard and profile.
  2. Use Dynamic Split to track time per user and bill for the current month.
  3. Run the Demo to see automatic recognition start a timer for a user.
  4. At month‑end, enter bill rates and export a printable report with each user’s share.
  5. For ad‑hoc costs, use the Expense Splitter to compute a fair split instantly.

Privacy & Security

  • Local‑first demo: facial recognition and timers run on your machine during development.
  • Auth0 handles authentication—no passwords stored in our app.
  • Secrets are managed via a local .env file and are not committed to Git.

Tech Stack

  • Flask (Python) for the web app and routing
  • Auth0 for authentication
  • Vanilla HTML/CSS/JS for the UI
  • OpenCV/face recognition (demo) for local user detection
